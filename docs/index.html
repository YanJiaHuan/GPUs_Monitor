🚀 About GPU Monitor

GPU Monitor is a real-time cluster-wide GPU monitoring dashboard that simplifies GPU resource management across multiple machines.

💡 Why Use GPU Monitor?

❌
No More Manual SSH
Stop logging into each machine individually to check GPU availability
⚡
Instant Overview
See all your GPUs across your entire cluster in one unified dashboard
🎯
Smart Status Detection
Automatically identifies busy/available GPUs based on memory and utilization
🔄
Live Updates
Auto-refreshes every 15 seconds to keep you informed in real-time

🎓 How It Works

1
Configure Once

Set up your devices in config.yaml with SSH credentials

2
Run the Server

Start the monitor with python app.py

3
Open Dashboard

Access the web interface from any device on your network

4
Monitor Easily

No more ssh user@host + nvidia-smi for each machine!

🛠️ Key Features

  • Multi-device monitoring - Track GPUs across unlimited machines
  • Real-time metrics - Utilization, memory usage, temperature, and more
  • Color-coded status - Instantly identify available (green) vs busy (orange) GPUs
  • Error detection - Quickly spot connection or hardware issues
  • Responsive design - Works on desktop, tablet, and mobile devices
  • Zero dependencies on GPU machines - Uses SSH to query nvidia-smi remotely
